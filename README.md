# Heat Transfer Boundary Conditions

An interactive tool for 1-D steady-state conduction through a plane wall under different boundary conditions.

## Live tool

[Open Heat Transfer Boundary Conditions](https://nuhaaljuneidi.github.io/ht_interactive_tool/)

## Features

- Six cases: fixed temperatures, fixed temperature plus flux, heat in from both sides, equal flux at both ends, convection, and insulated plus fixed temperature.
- Adjustable thermal conductivity and wall thickness.
- Temperature profile with a clear sign convention for heat flux.

## Run locally

Open `index.html` in a modern browser. No build step is needed.
